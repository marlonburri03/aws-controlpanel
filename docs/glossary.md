# Glossary and references

## Glossary

| Term | Definition |
|---|---|
| AWS CLI | Command-line tool for managing AWS resources and automating tasks in AWS |
| Bash | Unix shell and scripting language, commonly used for automation |
| Bash script | Script executed by the shell that automates a sequence of commands; the basis of the control panel |
| CI/CD pipeline | Automated process for continuous integration and delivery of code or infrastructure changes |
| cloud-init | Configuration system that runs at the first boot of a cloud instance and applies users, packages and settings |
| Definition of Done (DoD) | Agreed criteria that define when a story is complete |
| Definition of Ready (DoR) | Agreed criteria a story must meet before it can be planned into a sprint |
| EC2 instance | Virtual machine in AWS, for example a web or database server |
| Error handling | Structured detection of and reaction to error conditions, such as invalid input or missing resources |
| Git | Version control system for tracking changes to code |
| Infrastructure as Code (IaC) | Defining and versioning infrastructure as code |
| Init script | Central script that prepares the environment: paths, variables, colours, logging |
| Jira | Tool for planning and tracking backlogs, sprints and timelines |
| Logging | Recording actions and errors to make behaviour traceable |
| Modularisation | Structuring code into independent, reusable units such as separate scripts |
| Scrum | Agile framework that delivers work in short, iterative sprints |
| Security group | Virtual firewall that controls inbound and outbound traffic of AWS resources |
| Subnet | Address range within a VPC that segments IP addresses and routing |
| User story | Short description of a requirement from the user's point of view |
| VPC | Virtual Private Cloud: an isolated network in AWS for your resources |
